# Business Directory App

Android апликација за менаџирање и пребарување на компании, изработена во Android Studio со Java.

## Функционалности

* додавање компании
* приказ на компании по категории
* пребарување компании
* приказ на детали
* локално меморирање со Room Database
* navigation drawer
* swipe navigation помеѓу tabs
* notifications
* работа со географски координати

## Технологии

* Java
* Android Studio
* Room Database
* RecyclerView
* Fragments
* XML Layouts

## Дополнително

Во апликацијата се внесени и произволни компании со цел апликацијата да не биде празна при стартување и за полесно тестирање на функционалностите. Дополнително корисникот може самостојно да додава нови компании преку формата за внес.

Сите податоци се меморираат локално во Room Database и остануваат зачувани по затворање на апликацијата.
